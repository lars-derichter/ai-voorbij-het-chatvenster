# Tools en projecten om verder te verkennen

## Mijn favoriete tools

### Tekst editor

Mijn favoriete tekst editor is
[Visual Studio Code](https://code.visualstudio.com/), met de
[Markdown All in One](https://marketplace.visualstudio.com/items?itemName=yzhang.markdown-all-in-one)
extensie geïnstalleerd. Mijn favoriete theme is
[Nord](https://www.nordtheme.com/ports/visual-studio-code) (rustig voor de
ogen).

### Presentaties

Voor presentaties gebruik ik [Slidev](https://sli.dev/). Ik heb een eigen
[start template](https://github.com/lars-derichter/slidev-template), een
[persoonlijk theme](https://github.com/lars-derichter/ldr-slidev-theme) en een
aangepast
[Thomas More theme](https://github.com/lars-derichter/tm-slidev-theme).

### Markdown omzetten

De beste tool om markdown om te zetten naar andere formaten is
[Pandoc](https://pandoc.org/). Om andere formaten om te zetten in pandoc,
gebruik ik [MarkItDown](https://www.markitdown.de/en). (Zo verspil ik geen
tokens aan Word documenten, PDFs of Powerpoint presentaties in bronbestanden.)

### Typesetting

Als je mooie documenten wil maken, kan een typesetting systeem een goede hulp
zijn. Ik wil geen InDesign leren. De meeste (exacte) wetenschappers gebruiken
[LaTeX](https://www.latex-project.org/), maar een tijdje geleden ontdekte ik
[Typst](https://typst.app/). Beide systemen zijn ingewikkeld, maar zeer
bruikbaar in combinatie met een AI.

### Versiecontrole

[Git](https://git-scm.com/) is onmisbaar om tussenstappen en versies van een
project te bewaren. Als je een project dan ook nog eens synchroniseert naar
[GitHub](https://github.com/) weet je pas echt zeker dat je altijd terug kan
naar een vroegere versie. Zonder deze beveiliging zou ik een AI niet zomaar
vertrouwen met mijn bestanden.

## Persoonlijke AI-projecten

Voorbeelden van projecten die ik recent samen met AI maakte. Meestal vind je een
‘making of’ in de readme. Ter inspiratie.

- [Teaching programming to beginners](https://github.com/lars-derichter/teaching-programming-review):
  een gegenereerde wetenschappelijke literatuurstudie met een stand van zaken
  van het onderzoek rond hoe je beginners (jongvolwassenen) leert programmeren.
  Met een reader en een didactische leidraad erop gebaseerd. Dit is echt een eye
  opener van wat je met een beetje prompten en een goed model kan doen.
- [Learning Typst](https://github.com/lars-derichter/learning-typst-book): een
  gegenereerd boek om Typst te leren gebruiken. In de stijl van de O’Reilly
  boeken over programmeren. Zeer leesbaar, zeer bruikbaar. Kan een menselijke
  auteur beter? Ongetwijfeld, als die 6 maanden tijd heeft en een goede
  redacteur en een typesetter etc. Dit kostte me een paar uur.
- [The Legacy of Alberta](https://github.com/lars-derichter/albertas-legacy):
  een adventure game in de stijl van de vroege jaren ’90 (zoals King’s Quest) om
  programmeurstudenten op een entertainende manier te laten oefenen op een
  aantal basisconstructies.
- [Agent workflow](sources/blogpost-agentworkflow.md): een blog post die de
  complexe agent workflow voor de boekvertaling in meer detail beschrijft.

En last but not least: [Coursewright.md](https://coursewright.md/): een systeem
om cursusmateriaal in markdown te maken, te exporteren als website en te
synchronseren met Canvas. Met ingebouwde mogelijkheden om te exporteren naar
Word en PDF. Inclusief een heel aantal skills om op een didactisch onderbouwde
manier samen met AI cursusmaterialen te ontwikkelen. Gebruiken op eigen risico,
maar voor mezelf werkt het al erg goed.
